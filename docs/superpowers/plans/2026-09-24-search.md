# Search — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax. Each task ends green and committed. Read "Execution model" before starting a slice.

**Goal:** Quick open (`⌘P`, fuzzy on note names) and vault search (`⌘⇧F`, literal full text), both in one modal picker, both on `inkra-index`, usable at 50,000 notes.

**Architecture:** `inkra-index` gains two pure engines behind a narrow API (spec D1): `names` (fuzzy name matcher over an immutable `NamesSnapshot`) and `search` (literal matcher over an immutable `CorpusSnapshot`). `NoteIndex` (renamed from `LinkIndex`) owns membership, links, names and corpus, and changes them together. `app` gets a generic `Picker<D>`, a modal layer in `AppShell`, and one delegate per feature. The delegates run the engines on gpui's background executor with cancellation.

**Tech Stack:** Rust 2024, gpui (vendored), `unicode-normalization` 0.1.25 (present), `regex` 1.13 (slice 4, already in `Cargo.lock`), `proptest`, `criterion` 0.8.

**Spec:** `docs/superpowers/specs/2026-09-24-search-design.md`. Read it whole before any slice. Each slice below names the decisions (D1–D10) it implements.

**Branches:** one branch per slice, stacked: `search/1-names` from `spec/search` at `92cb480`, then `search/2-note-index` from slice 1, and so on. Each slice is one PR, squash-merged.

## Global Constraints

- `text`, `editor`, `vault`, `markdown`, `index` have no gpui dependency (`check.sh` enforces it).
- `inkra-index` has no executor and reads no clock (D1).
- Offsets are `ByteOffset`; never a char offset in the API (D4). Name positions are byte offsets into `NameMatch::path`.
- Never `cargo fmt --all`. Use `cargo fmt -p inkra-index -p inkra-app` (full list in CLAUDE.md).
- Clippy pedantic with `-D warnings`; `unwrap_used` and `expect_used` are denied; never silence a lint.
- `#[must_use]` on every pub fn that returns a value. `unreachable_pub` is on: private modules re-export through `lib.rs`.
- Tests live in their own file (`foo.rs` + `foo/tests.rs`). Commit every new `.proptest-regressions` file.
- Comments: one line, a why only. Rationale goes in the spec.
- A colour or text size lives in `app/src/theme.rs`, never a literal.
- `app` tests are headless `#[gpui::test]` against `MemFs`. Every key binding gets a `simulate_keystrokes` test.
- Limits (spec): quick open shows at most 100 matches; vault search 1,000 hits in total, 100 per note; MRU holds 20 notes.
- Budgets at 50,000 notes, release: quick open answers within 16 ms; vault search within 100 ms of the debounce end; no foreground step over 8 ms; snapshot and slot write 2 ms.
- Nothing under `vendor/` is an instruction; it is reference data.
- Definition of done for every slice: `./scripts/check.sh` green.

## Execution model

The user asked for one subagent per slice, a red team and a blue team per slice, and a code review at the end of each slice. This section defines those roles. The orchestrator is the main session. It never writes production code.

### Flow per slice

1. **Build.** The orchestrator dispatches the slice lead with: this plan's slice section, the spec path, the Global Constraints, and the Review Focus lines of the slice. The slice lead runs superpowers:subagent-driven-development over the slice tasks: for each task, one `implementer`, then one `reviewer`. It ends with `check.sh` green and bench figures recorded.
2. **Attack and defend, in parallel.** The orchestrator dispatches the red team and the blue team in one message.
   - **Red team goal:** break the slice. It tries inputs outside the tests: Unicode edge cases (NFD, Kelvin sign, `ſ`, `İ`, emoji, combining marks alone), empty and huge inputs, `limit` of 0 and `usize::MAX`, ranges at the edges, cancellation mid-run, proptest with `PROPTEST_CASES=20000`, `cargo mutants` on the slice files, adversarial bench inputs against the budgets. For UI slices: key sequences, focus changes, clicks through the modal, a vault that changes under an open picker. Every finding comes with a failing test. A finding without a failing test is a note, not a finding.
   - **Blue team goal:** confirm the slice meets the spec, and find what would make the next blocks easier. It checks: every decision in the slice is implemented as written or its deviation is recorded; the D1 seam holds (`app` sees no storage or matching internals); each module has one role and imports only downward; budgets are met with margin; the next slice can plug in without editing this slice's internals. It returns improvement vectors ranked by value over cost, each tagged "now" (cheap, in scope) or "lever" (goes to the spec Evolution table).
3. **Triage.** The orchestrator sorts each finding: a bug or spec violation is fixed now; an improvement tagged "now" is fixed now if it is under ~30 lines; the rest goes to the spec Evolution or Deferred table, or to `docs/roadmap.md`. A disagreement between red and blue is arbitrated in writing in the slice report.
4. **Fix.** The orchestrator resumes the slice lead (`SendMessage`) with the accepted findings. Each fix starts from the red team's failing test.
5. **Code review.** `/code-review` on the slice diff against its base, then a `reviewer` against this plan's slice section. Findings go back to step 4. Builder is never verifier.
6. **Gate.** All of: `./scripts/check.sh` green; `./scripts/test-names.sh` diff clean if a file was split; `cargo mutants` zero missed on the slice's index files (slices 1, 2, 4, 5); shots rendered and looked at (slices 3, 6); bench figures recorded in the spec (slices 1, 2, 4, 5).
7. **Report and stop.** The orchestrator reports to the user: what shipped, gate evidence, deferred findings. It opens the slice PR only on the user's go, and starts the next slice only after that.

### Lego rule

Each slice adds one block with one role and a narrow face. A later block consumes an earlier block only through its public API; it never reaches into its fields. The red and blue teams check this. Concretely:

- `names` and `search` never import each other. Both use `chunks::split`.
- `NoteIndex` composes `NoteTable`, link sources, `NamesSnapshot` and `Corpus`; it holds no matching logic.
- `Picker<D>` knows no feature. A delegate knows no other delegate. `AppShell` knows the modal, not the delegates' internals.

## Slice 1 — `names` (detailed)

Spec: D1 (API), D2 (matcher), "Performance and the benches" (`names`), "Testing" (oracles). Branch `search/1-names`.

### Decisions this plan makes inside the spec

Record these in the spec's D2 in Task 1.4, in one short paragraph.

- **`NameMatch` carries `path: Arc<str>`.** The positions index the NFC path the index stores, not the vault's path, which is NFD on macOS. A row must draw the same string, so the match carries it, as `Hit` carries `context` (D1). The clone is an `Arc` bump.
- **Positions are byte offsets into `NameMatch::path`**, on char starts. "Positions index the path's chars as stored" (D2) is read that way; `StyledText::with_highlights` takes byte ranges.
- **No mutable `Names` type.** Names change only by `set_notes`, so `NoteSet` holds a `NamesSnapshot` and `names()` clones it.
- **`match_names` handles the empty query.** It returns the recent notes present in the range, without `showing`, by MRU rank. A recent id no longer in the vault is not found, so `app` does no filtering (D6's "dropped when the list is read" happens here).
- **`NoteSet::names()` is public** in slice 1, so tests and the bench reach names before `NoteIndex` exists. Slice 2 keeps it.
- **Score constants** (integers, D2's table): match 16; boundary bonus 24; stem-start bonus 32; consecutive bonus 16; gap of `g` chars costs `min(3 + g − 1, 12)`; a term wholly in the stem gains 8 per char; exact stem 1024; the note showing loses `score / 4`. No leading-gap penalty.

```rust
use std::ops::Range;

/// At most `n` non-empty ranges, in order, covering `0..len`; none when `len` is 0.
pub(crate) fn split(len: usize, n: usize) -> Vec<Range<usize>> {
    let n = n.clamp(1, len.max(1));
    (0..n)
        .map(|k| k * len / n..(k + 1) * len / n)
        .filter(|range| !range.is_empty())
        .collect()
}
```

```rust
use std::iter;

use unicode_normalization::UnicodeNormalization;

/// A path char as the name matcher compares it (spec D2).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) struct PathChar {
    pub(crate) exact: char,
    /// The first char of the NFD decomposition, lowercased: `É` → `e`.
    pub(crate) base: char,
}

/// A query char, lowercased; `plain` when it has no diacritic.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) struct QueryChar {
    pub(crate) c: char,
    pub(crate) plain: bool,
}

/// A char whose lowercase is several chars compares by the first.
fn lower(c: char) -> char {
    c.to_lowercase().next().unwrap_or(c)
}

impl PathChar {
    pub(crate) fn new(c: char) -> Self {
        let first = iter::once(c).nfd().next().unwrap_or(c);
        Self {
            exact: lower(c),
            base: lower(first),
        }
    }
}

impl QueryChar {
    pub(crate) fn new(c: char) -> Self {
        let c = lower(c);
        Self {
            c,
            plain: iter::once(c).nfd().nth(1).is_none(),
        }
    }

    /// Case always folds; accents fold only from a plain query char, as nucleo's `Smart`.
    pub(crate) fn matches(self, path: PathChar) -> bool {
        self.c == path.exact || (self.plain && self.c == path.base)
    }
}

#[cfg(test)]
mod tests;
```

```rust
/// Which chars a string holds, hashed to 64 bits. A collision only lets a candidate through
/// to the exact check, so the filter never rejects a match.
#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub(crate) struct CharBag(u64);

impl CharBag {
    pub(crate) fn insert(&mut self, c: char) {
        self.0 |= 1 << slot(c);
    }

    pub(crate) fn contains_all(self, other: Self) -> bool {
        self.0 & other.0 == other.0
    }
}

fn slot(c: char) -> u32 {
    match c {
        'a'..='z' => c as u32 - 'a' as u32,
        '0'..='9' => 26 + (c as u32 - '0' as u32),
        _ => 36 + c as u32 % 28,
    }
}
```

```rust
use std::ops::Range;
use std::sync::Arc;

use inkra_vault::EntryId;

use crate::chunks::split;

mod bag;
mod fold;
mod score;

use bag::CharBag;
use fold::PathChar;

/// One note as quick open matches it. Built once per `set_notes`, off the foreground.
pub(crate) struct Candidate {
    id: EntryId,
    /// NFC, `/`-separated, `.md` stripped.
    pub(crate) path: Arc<str>,
    chars: Box<[PathChar]>,
    /// Per char: the boundary and stem-start bonus, which depend on the path alone.
    bonus: Box<[u8]>,
    /// Char index where the stem starts.
    stem: usize,
    bag: CharBag,
}

impl Candidate {
    fn new(id: EntryId, path: String) -> Self {
        let raw: Vec<char> = path.chars().collect();
        let stem = raw.iter().rposition(|&c| c == '/').map_or(0, |at| at + 1);
        let chars: Box<[PathChar]> = raw.iter().map(|&c| PathChar::new(c)).collect();
        let bonus = (0..raw.len()).map(|at| score::bonus(&raw, at, stem)).collect();
        let mut bag = CharBag::default();
        for c in &chars {
            bag.insert(c.exact);
            bag.insert(c.base);
        }
        Self {
            id,
            path: path.into(),
            chars,
            bonus,
            stem,
            bag,
        }
    }
}

/// The quick-open candidates in vault order. Cloning is an `Arc` bump.
#[derive(Clone, Default)]
pub struct NamesSnapshot(Arc<[Candidate]>);

impl NamesSnapshot {
    pub(crate) fn build(notes: impl IntoIterator<Item = (EntryId, String)>) -> Self {
        Self(notes.into_iter().map(|(id, path)| Candidate::new(id, path)).collect())
    }

    #[must_use]
    pub fn len(&self) -> usize {
        self.0.len()
    }

    #[must_use]
    pub fn is_empty(&self) -> bool {
        self.0.is_empty()
    }

    /// Ranges to match in parallel; `merge_names` over their results equals one range.
    #[must_use]
    pub fn chunks(&self, n: usize) -> Vec<Range<usize>> {
        split(self.0.len(), n)
    }

    pub(crate) fn candidates(&self) -> &[Candidate] {
        &self.0
    }
}
```

```rust
pub(super) const BOUNDARY: u8 = 24;
pub(super) const STEM_START: u8 = 32;

/// A match here gains this, on top of the base score: a word start, a case change, the stem.
pub(super) fn bonus(raw: &[char], at: usize, stem: usize) -> u8 {
    let boundary = at == 0 || {
        let (prev, cur) = (raw[at - 1], raw[at]);
        matches!(prev, '/' | '-' | '_' | ' ' | '.') || (prev.is_lowercase() && cur.is_uppercase())
    };
    u8::from(boundary) * BOUNDARY + u8::from(at == stem) * STEM_START
}
```

**Files:** create `names/query.rs`, `names/matching.rs`, `names/tests.rs`; complete `names/score.rs`; modify `names.rs`, `lib.rs`.

**Interfaces:**
- Consumes: `Candidate`, `NamesSnapshot`, `QueryChar`, `CharBag`, `score::bonus` (Tasks 1.1–1.2).
- Produces (public, re-exported from `lib.rs`):
  - `pub struct NameQuery` (`Debug`, `Clone`) — `NameQuery::new(text: &str, showing: Option<EntryId>, recent: &[EntryId]) -> NameQuery`, `is_empty(&self) -> bool`.
  - `pub struct NameMatch { pub id: EntryId, pub path: Arc<str>, pub score: i32, pub positions: Vec<usize>, rank: Rank }` (`Debug`, `Clone`, `PartialEq`, `Eq`).
  - `pub fn match_names(names: &NamesSnapshot, range: Range<usize>, query: &NameQuery, cancel: &AtomicBool, limit: usize) -> Vec<NameMatch>`.
  - `pub fn merge_names(chunks: Vec<Vec<NameMatch>>, limit: usize) -> Vec<NameMatch>`.

Semantics:
- A note matches when every term (the NFC query split on whitespace) is a subsequence of its path by `QueryChar::matches`, in any term order.
- Score = sum over terms of the best alignment (DP, constants above), + 1024 when the terms as typed, joined by one space, equal the stem by the char rule (spec D2, "Settled in the plan"; the code block below predates that rule), then `− score / 4` for `showing`.
- Order = `(score desc, MRU rank asc with absent last, path chars asc, vault order asc)`. Vault order is unique, so the order is total.
- Empty query: the recent notes in range, without `showing`, score 0, no positions.
- `cancel` is checked before each block of 1,024 candidates; when set, the result is empty.
- `positions`: byte offsets into `path` of every char any term's best alignment matched, ascending, without repeats. Computed only for the kept matches.

```rust
use inkra_vault::EntryId;
use unicode_normalization::UnicodeNormalization;

use super::bag::CharBag;
use super::fold::QueryChar;

/// A quick-open query, prepared once per keystroke and shared by every range.
#[derive(Debug, Clone)]
pub struct NameQuery {
    pub(super) terms: Vec<Vec<QueryChar>>,
    pub(super) bag: CharBag,
    pub(super) showing: Option<EntryId>,
    recent: HashMap<EntryId, usize>,
}

impl NameQuery {
    /// `recent` is newest first; `showing` is the note on screen, ranked down.
    #[must_use]
    pub fn new(text: &str, showing: Option<EntryId>, recent: &[EntryId]) -> Self {
        let text: String = text.nfc().collect();
        let terms: Vec<Vec<QueryChar>> = text
            .split_whitespace()
            .map(|term| term.chars().map(QueryChar::new).collect())
            .collect();
        let mut bag = CharBag::default();
        for c in terms.iter().flatten() {
            bag.insert(c.c);
        }
        // Reversed so a repeated id keeps its newest rank.
        let recent = recent
            .iter()
            .enumerate()
            .rev()
            .map(|(rank, id)| (*id, rank))
            .collect();
        Self {
            terms,
            bag,
            showing,
            recent,
        }
    }

    #[must_use]
    pub fn is_empty(&self) -> bool {
        self.terms.is_empty()
    }

    pub(super) fn recent(&self, id: EntryId) -> Option<usize> {
        self.recent.get(&id).copied()
    }
}
```

```rust
use super::Candidate;
use super::fold::QueryChar;
use super::query::NameQuery;

const MATCH: i32 = 16;
const CONSECUTIVE: i32 = 16;
/// A gap of `g` chars costs `GAP_OPEN + g - 1`, at most `GAP_MAX`.
const GAP_OPEN: i32 = 3;
const GAP_MAX: i32 = 12;
const IN_STEM: i32 = 8;
const EXACT_STEM: i32 = 1024;
/// Far enough below any score that a few penalties cannot reach a real one.
const NONE: i32 = i32::MIN / 2;

/// `None` when some term is not a subsequence of the path.
pub(super) fn score(note: &Candidate, query: &NameQuery, table: &mut Vec<i32>) -> Option<i32> {
    if !note.bag.contains_all(query.bag) || !query.terms.iter().all(|term| fits(note, term)) {
        return None;
    }
    let mut total = 0;
    for term in &query.terms {
        total += best(note, term, table)?.0;
    }
    if let [term] = query.terms.as_slice()
        && is_stem(note, term)
    {
        total += EXACT_STEM;
    }
    if query.showing == Some(note.id) {
        total -= total / 4;
    }
    Some(total)
}

/// Byte offsets into `note.path` of the chars the best alignments matched, ascending.
pub(super) fn positions(note: &Candidate, query: &NameQuery, table: &mut Vec<i32>) -> Vec<usize> {
    let mut at = Vec::new();
    for term in &query.terms {
        let Some((_, from)) = best(note, term, table) else {
            continue;
        };
        fill(note, term, from, table);
        backtrack(note, term, from, table, &mut at);
    }
    at.sort_unstable();
    at.dedup();
    let offsets: Vec<usize> = note.path.char_indices().map(|(offset, _)| offset).collect();
    at.into_iter().map(|index| offsets[index]).collect()
}

/// Cheap reject before the DP: greedy subsequence.
fn fits(note: &Candidate, term: &[QueryChar]) -> bool {
    let mut chars = note.chars.iter();
    term.iter().all(|q| chars.any(|&c| q.matches(c)))
}

fn is_stem(note: &Candidate, term: &[QueryChar]) -> bool {
    let stem = &note.chars[note.stem..];
    stem.len() == term.len() && term.iter().zip(stem).all(|(q, &c)| q.matches(c))
}

/// The term's best score and the char it was aligned from: the whole path, or the stem alone
/// with its bonus.
fn best(note: &Candidate, term: &[QueryChar], table: &mut Vec<i32>) -> Option<(i32, usize)> {
    let whole = fill(note, term, 0, table)?;
    let length = i32::try_from(term.len()).unwrap_or(i32::MAX);
    let in_stem = fill(note, term, note.stem, table).map(|s| s + IN_STEM.saturating_mul(length));
    Some(match in_stem {
        Some(in_stem) if in_stem >= whole => (in_stem, note.stem),
        _ => (whole, 0),
    })
}

/// Fills `table` (term chars × path chars, row-major) with the best score of `term[..=j]`
/// ending at each char from `from` on. O(chars × term) with the gap cap: a gap score is the
/// better of an affine run and the row's prefix max minus `GAP_MAX`.
fn fill(note: &Candidate, term: &[QueryChar], from: usize, table: &mut Vec<i32>) -> Option<i32> {
    let n = note.chars.len();
    table.clear();
    table.resize(term.len() * n, NONE);
    for (j, &q) in term.iter().enumerate() {
        let (above, rest) = table.split_at_mut(j * n);
        let row = &mut rest[..n];
        let prev = j.checked_sub(1).map(|up| &above[up * n..]);
        let (mut affine, mut prefix) = (NONE, NONE);
        for at in from..n {
            let reach = match prev {
                None => 0,
                Some(prev) => {
                    if at >= from + 2 {
                        affine = (affine - 1).max(prev[at - 2] - GAP_OPEN);
                        prefix = prefix.max(prev[at - 2]);
                    }
                    let consecutive = if at > from { prev[at - 1] + CONSECUTIVE } else { NONE };
                    consecutive.max(affine).max(prefix - GAP_MAX)
                }
            };
            if reach > NONE / 2 && q.matches(note.chars[at]) {
                row[at] = reach + MATCH + i32::from(note.bonus[at]);
            }
        }
    }
    let last = term.len().checked_sub(1)? * n;
    table[last..].iter().copied().max().filter(|&best| best > NONE / 2)
}

fn gap(chars: usize) -> i32 {
    i32::try_from(chars).map_or(GAP_MAX, |chars| GAP_OPEN.saturating_add(chars - 1).min(GAP_MAX))
}

/// Walks `table` back from the best last cell, preferring a consecutive predecessor, and
/// pushes each matched char index.
fn backtrack(note: &Candidate, term: &[QueryChar], from: usize, table: &[i32], out: &mut Vec<usize>) {
    let n = note.chars.len();
    let last = term.len() - 1;
    let row = &table[last * n..];
    let Some(mut at) = (from..n).filter(|&i| row[i] > NONE / 2).max_by_key(|&i| (row[i], std::cmp::Reverse(i))) else {
        return;
    };
    out.push(at);
    for j in (0..last).rev() {
        let reach = table[(j + 1) * n + at] - MATCH - i32::from(note.bonus[at]);
        let prev = &table[j * n..(j + 1) * n];
        let step = |k: usize| if k + 1 == at { CONSECUTIVE } else { -gap(at - 1 - k) };
        let Some(k) = (from..at).rev().find(|&k| prev[k] > NONE / 2 && prev[k] + step(k) == reach) else {
            unreachable!("a filled cell has the predecessor that filled it");
        };
        at = k;
        out.push(at);
    }
}
```

```rust
use std::cmp::Reverse;
use std::collections::BinaryHeap;
use std::ops::Range;
use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};

use inkra_vault::EntryId;

use super::query::NameQuery;
use super::{NamesSnapshot, score};

const CANCEL_EVERY: usize = 1024;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct NameMatch {
    pub id: EntryId,
    /// The path `positions` index: NFC, `/`-separated, `.md` stripped.
    pub path: Arc<str>,
    pub score: i32,
    /// Byte offsets into `path` of the matched chars, ascending.
    pub positions: Vec<usize>,
    rank: Rank,
}

/// Spec D2's order; smaller is better. `order` is unique, so the order is total.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
struct Rank {
    score: Reverse<i32>,
    recent: usize,
    chars: usize,
    order: usize,
}

/// The best `limit` matches in `range`, best first. Empty when `cancel` is set.
#[must_use]
pub fn match_names(
    names: &NamesSnapshot,
    range: Range<usize>,
    query: &NameQuery,
    cancel: &AtomicBool,
    limit: usize,
) -> Vec<NameMatch> {
    let notes = names.candidates();
    let mut kept: BinaryHeap<Rank> = BinaryHeap::new();
    let mut table = Vec::new();
    for block in range.clone().step_by(CANCEL_EVERY) {
        if cancel.load(Ordering::Relaxed) {
            return Vec::new();
        }
        for order in block..(block + CANCEL_EVERY).min(range.end) {
            let note = &notes[order];
            let score = if query.is_empty() {
                query.recent(note.id).filter(|_| query.showing != Some(note.id)).map(|_| 0)
            } else {
                score::score(note, query, &mut table)
            };
            let Some(score) = score else {
                continue;
            };
            kept.push(Rank {
                score: Reverse(score),
                recent: query.recent(note.id).unwrap_or(usize::MAX),
                chars: note.chars.len(),
                order,
            });
            if kept.len() > limit {
                kept.pop();
            }
        }
    }
    kept.into_sorted_vec()
        .into_iter()
        .map(|rank| {
            let note = &notes[rank.order];
            NameMatch {
                id: note.id,
                path: Arc::clone(&note.path),
                score: rank.score.0,
                positions: score::positions(note, query, &mut table),
                rank,
            }
        })
        .collect()
}

/// Joins the ranges' results; equals one `match_names` over their union.
#[must_use]
pub fn merge_names(chunks: Vec<Vec<NameMatch>>, limit: usize) -> Vec<NameMatch> {
    let mut all: Vec<NameMatch> = chunks.into_iter().flatten().collect();
    all.sort_unstable_by_key(|found| found.rank);
    all.truncate(limit);
    all
}
```

```rust
    let query: String = query.nfc().collect();
    query.split_whitespace().all(|term| {
        let mut chars = path.iter();
        term.chars().map(QueryChar::new).all(|q| chars.any(|&c| q.matches(c)))
    })
}

fn notes(all: &[(EntryId, String, Kind)]) -> Vec<(EntryId, String)> {
    all.iter()
        .filter(|(_, _, kind)| *kind == Kind::Note)
        .map(|(id, path, _)| (*id, strip_md(path).nfc().collect()))
        .collect()
}
```

## Slice 2 — `NoteIndex` and `IndexSync` (detailed)

Spec: D1 (`NoteIndex`, `NoteSet`), D5 (`IndexSync`), "Performance and the benches" (`set_notes`), "Testing" (`NoteIndex`, `IndexSync`). Branch `search/2-note-index` from `search/1-names`.

### Decisions this plan makes inside the spec

Record these in the spec's D5 in Task 2.4, in one short paragraph.

- **`NoteSet` owns the one preparation pass.** `note_set::prepare` filters the notes, strips `.md` and normalizes to NFC once (with slice 1's ASCII skip), into `Vec<(EntryId, Arc<str>)>`. `NoteTable::new` borrows that list; `NamesSnapshot::build` consumes it. Both hold the same `Arc<str>` per path.
- **`insert` keeps its slice-1 signature.** The `text` argument of D1 lands in slice 5 with the corpus.
- **Stale builds are dropped by a generation counter**, as D5 states. `generation` counts builds started; `built` is the last one applied. A build applies only when its generation equals `generation`.
- **`is_building()` covers the build too.** It is true from `reconcile` until the build applies and every queued load ends. It reads `progress()`, so `progress()` has a caller before slice 6. Without it the backlinks panel would say "no backlinks" during the startup build, where today it says it is building.
- **A save that lands before its note joins the index is reloaded.** The build is now asynchronous, so a `NoteSaved` for a note created a moment ago can reach `apply` before `set_notes` makes it a member. `insert` ignores it, as for a trashed note. `apply` then forgets the note's recorded mtime, so the next mtime diff queues a load. Without this, the note's links would be lost until its next edit.
- **Stale-build and early-save tests are white-box.** A `NoteSet::build` is pure CPU; no `MemFs` gate can hold it, and gpui's test scheduler orders background tasks at random. The tests call `apply_notes` and `apply` directly from `index/tests.rs`, a child module. Every other test goes through `MemFs` and the vault.

```rust
    pub(crate) names: NamesSnapshot,

    /// `entries` in `Vault::entries()` order, paths relative to the root; folders are dropped.
    #[must_use]

        let notes = prepare(entries);
        Self {
            notes: NoteTable::new(&notes),
            names: NamesSnapshot::build(notes),
        }

        self.names.clone()

/// The notes of `entries` in order, `.md` stripped, NFC: the one pass both halves share.
pub(crate) fn prepare(entries: Vec<(EntryId, String, Kind)>) -> Vec<(EntryId, Arc<str>)> {
    entries
        .into_iter()
        .filter(|(_, _, kind)| *kind == Kind::Note)
        .map(|(id, path, _)| {
            let path = strip_md(&path);
            let path: Arc<str> = if path.is_ascii() {
                path.into()
            } else {
                path.nfc().collect::<String>().into()
            };
            (id, path)
        })
        .collect()
}
```

```rust
    fn reconcile(&mut self, cx: &mut Context<Self>) {
        let Some(vault) = &self.vault else {
            return;
        };
        let entries: Vec<(EntryId, String, Kind)> = vault
            .read(cx)
            .entries()
            .map(|entry| {
                let path = entry.path.as_path().to_string_lossy().into_owned();
                (entry.id, path, entry.kind)
            })
            .collect();
        self.generation += 1;
        let generation = self.generation;
        let build = cx.background_spawn(async move { NoteSet::build(entries) });
        // Detached: it holds only a weak handle, so it ends when this entity does.
        cx.spawn(async move |this, cx| {
            let notes = build.await;
            let _ = this.update(cx, |this, cx| this.apply_notes(generation, notes, cx));
        })
        .detach();
        cx.notify();
    }

    /// Applies a build unless a newer one started, then queues every note whose mtime differs
    /// from the one it was indexed at.
    fn apply_notes(&mut self, generation: u64, notes: NoteSet, cx: &mut Context<Self>) {
        if generation != self.generation {
            return;
        }
        self.built = generation;
        self.index.set_notes(notes);
        let Some(vault) = self.vault.clone() else {
            return;
        };
        let vault = vault.read(cx);
        // the old body from `let notes: Vec<(EntryId, Mtime)> = …` to `cx.notify();`, unchanged
    }
```

`progress` and `is_building`:

```rust
    /// `(loaded, total)`: the notes of the last build, less those queued or loading.
    pub(crate) fn progress(&self) -> (usize, usize) {
        let total = self.index.names().len();
        let pending = self.queued.len() + usize::from(self.loading);
        (total.saturating_sub(pending), total)
    }

    /// True from a vault change until its build applies and its loads end; a write's own
    /// parse does not count.
    pub(crate) fn is_building(&self) -> bool {
        let (loaded, total) = self.progress();
        self.built != self.generation || loaded < total
    }
```
