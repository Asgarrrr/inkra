> **For agentic workers:** steps use checkbox (`- [ ]`) syntax. Written by an
> Opus planner on 2026-09-29; red/blue reviewed (Sonnet), findings folded in.

**Goal:** a new crate, `inkra-tabs`, whose `Tabs<P>` holds stable `TabId`s,
open/activate/close, an MRU and the index rule. The shell holds
`Tabs<Place>`. A switch to a loaded note is synchronous; an async open commits
on landing, keyed by `TabId`. Keys: `⌘T`, `⌘W`, next/previous, `⌘1`–`⌘9`.
Trash empties the tabs showing a note. A tab bar sits above the note column,
and a `tabs` scene renders it.

## Decisions settled from the code

1. **`cmd-shift-]` never fires on a Mac; bind `cmd-}` / `cmd-{`.**
   `gpui_macos/src/events.rs:470-479` clears `shift` for a non-letter key and
   reports the shifted character; `KeybindingKeystroke::should_match` compares
   key and modifiers exactly (`gpui/src/platform/keystroke.rs:82-113`). A
   `cmd-shift-]` binding would pass `simulate_keystrokes` and be dead on
   hardware. `ctrl-shift-tab` is safe: tab keeps its shift
   (`events.rs:364-374`). Record as a spec deviation.
2. **An action handler must not call `cx.with_window`.** `App::with_window`
   returns `None` while the window is leased (`gpui/src/app.rs:1966-1976`;
   `update_window_erased` takes it out, `:2884-2887`). Today's editor drop
   (`shell.rs:86-99`) runs from a subscription, where the window is free. Tab
   actions hold the window, so `drop_editor` takes `&mut Window`; only the
   `NoteClosed` subscription wraps it in `with_window`.
3. **`ActivateTab(usize)` is a data action:** `#[derive(Clone, PartialEq,
   Debug, gpui::Action)] #[action(namespace = tabs, no_json)]`
   (`gpui_macros/src/derive_action.rs:43-47`, `:121`). It cannot be built by
   default, so the palette leaves it out (`gpui/src/key_dispatch.rs:370-372`,
   read by `command_palette/commands.rs:115`) — intended. The unit actions
   (`NewTab`, `CloseTab`, `NextTab`, `PreviousTab`, `ActivateLastTab`) show in
   the palette.
4. **Zed's conventions:** a new tab goes right after the active one
   (`pane.rs:1265-1274`); closing the active tab activates the MRU head, else
   the left neighbour (`pane.rs:2135-2170`); next/previous wrap
   (`pane.rs:253-279`, `:1531-1557`); `⌘N` past the end does nothing and `⌘9`
   is the last tab (`pane.rs:1591-1598`); tabs use `on_click`, × closes by a
   stable id (`pane.rs:2921`, `:3031-3034`); the bar is `overflow_x_scroll` +
   `track_scroll` with `scroll_to_item` on activation (`pane.rs:3685-3695`,
   `:1510-1515`; `gpui/src/elements/div.rs:4316`).
5. **Capture seals the undo group with `Entity::update`, never `as_mut`**
   (precedent `vault/session/mod.rs:50-53`: `as_mut` notifies on drop).
6. **Same-note restore skips the rebind.** `open_buffer` resubscribes and
   reparses (`editor/mod.rs:93-121`); a new `EditorView::restore` resets the
   state and viewport only, without `TextInput::rebind` (`text_input.rs:85-90`).
   The S0 lever "a clipped-selection type for `rebind`" stays untriggered:
   both paths clip through `ViewState::clipped` (`editor/mod.rs:45-56`).
7. **The first tab's note is `NoteStore::current()` at construction.**
   `adopt` sets it to `DETACHED` for a file launch (`vault/store.rs:148-163`),
   `None` for a vault. `current()` and `buffer_for` lose `#[cfg(test)]`
   (`store.rs:76-84`). A tab's note is always loaded (nothing evicts; trash
   empties the tab), so a switch reads `buffer_for` synchronously.
8. **`showing` stays a field, written only by `set_showing`**
   (`shell/activation.rs:85-93`); tests assert it equals the active tab's note
   after every update (T1). `shell/tests/mod.rs:79-83` and many tests read it.

## Invariants

Model (`inkra-tabs`), each a proptest or unit test:

- **M1** (spec 1): at least one tab; closing the last leaves one empty tab with
  a **fresh** id, so a load keyed by the old id cannot land in it.
- **M2** (spec 2): ids unique, never reused; the active id is a tab.
- **M3** (spec 3): the MRU is a permutation of the ids, active first.
- **M4** (spec 8's index rule): `insert(at, …)` lands at `min(at, len)`;
  `close` returns the tab's index, and inserting the closed place back there
  restores the order.
- **M5:** `leaving` runs at most once, exactly when the active tab is left or
  closed; its value is stored in the tab left and returned when it is
  activated again.
- **M6:** closing the active tab activates the MRU's next id; closing another
  tab keeps the active one.
- **M7:** `commit(id, …)` writes only when `id` is active, else returns
  `false` and changes nothing.
- **M8:** `forget(pred)` sets matching places to `P::default()`, touches
  nothing else, and reports whether the active tab matched.
- **M9:** `step` wraps both ways; `id_at` past the end is `None`.

App:

- **T1:** `showing == tabs.active_place().note` after every shell update;
  `set_showing` is its one writer.
- **T2:** `editor.is_some() == showing.is_some()`: an empty tab has no editor.
- **T3:** `NoteStore::current == showing` once `NoteClosed` is handled (trash
  clears `current` first, `vault/tree_ops.rs:47-49`).
- **T4:** every tab operation drops `activation`; a landing load commits only
  into the `TabId` active when it started.
- **T5:** capture seals the undo group through `update`, only when the active
  tab is actually left.
- **T6:** a tab key dismisses an open picker before it acts.
- **T7:** the tab bar is a sibling of the editor's slot, outside
  `EditorView`'s scroll `div` (S0's P5, `editor/mod.rs:317-325`).
- **T8:** colours and sizes from `theme.rs`; UI copy ("New tab") in `tab_bar.rs`.

## `inkra-tabs` API

`crates/tabs/src/lib.rs`, no gpui, clock or file. Pure queries carry
`#[must_use]` (clippy pedantic).

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct TabId(u64);

#[derive(Debug, Clone)]
pub struct Tab<P> { id: TabId, place: P }            // S4 adds back/forward stacks here
impl<P> Tab<P> { pub fn id(&self) -> TabId; pub fn place(&self) -> &P; }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Direction { Next, Previous }

#[derive(Debug, Clone, PartialEq)]
pub struct Closed<P> {
    pub place: P,                   // fresh (`leaving`) if it was active
    pub index: usize,               // S5 reopens here, clamped (M4)
    pub shown: Option<(TabId, P)>,  // the tab now active, when the active tab closed
}

pub struct Tabs<P> { tabs: Vec<Tab<P>>, active: TabId, mru: Vec<TabId>, next: u64 }

impl<P: Clone + Default> Tabs<P> {
    pub fn new(first: P) -> Self;
    pub fn active(&self) -> TabId;
    pub fn active_index(&self) -> usize;
    pub fn active_place(&self) -> &P;
    pub fn count(&self) -> usize;   // not `len`: clippy's len_without_is_empty
    pub fn iter(&self) -> impl ExactSizeIterator<Item = &Tab<P>>;
    pub fn id_at(&self, index: usize) -> Option<TabId>;
    pub fn last(&self) -> TabId;
    pub fn step(&self, direction: Direction) -> TabId;
    pub fn insert(&mut self, at: usize, place: P, leaving: impl FnOnce() -> P) -> TabId;
    pub fn activate(&mut self, id: TabId, leaving: impl FnOnce() -> P) -> Option<P>;
    pub fn close(&mut self, id: TabId, leaving: impl FnOnce() -> P) -> Option<Closed<P>>;
    pub fn commit(&mut self, id: TabId, place: P, leaving: impl FnOnce() -> P) -> bool;
    pub fn forget(&mut self, gone: impl Fn(&P) -> bool) -> bool;
}
```

`activate` returns the arriving place, or `None` if already active or unknown.
`insert` activates the new tab; `app` shows the place it passed in.
`leaving` is a closure so `app` reads the view and seals the undo group only
when a tab is really left (`⌘1` on the active tab, × on an inactive one, seal
nothing). **It is called from exactly one place**, a private
`leave_active(&mut self, leaving: impl FnOnce() -> P)` that stores
`leaving()` in the active tab. `insert`, `activate`, `close` and `commit` go
through it, and `close`/`commit` only when `id == self.active`; for any other
id they touch neither `leaving` nor the active tab. "Drop its value" is not
"don't call it": the closure seals an undo group, so an unconditional call
would split the user's typing on an unrelated close or a late load. In S1,
`close` and `commit` drop the stored place's copy; S4 pushes it on `back`.

**Growth in S4/S5 without reshaping:** `Tab<P>` gains private `back` and
`forward` stacks (1024 each); `commit` pushes `leaving` on back and clears
forward; `back(id, leaving)` / `forward(id, leaving)` return `Option<P>` like
`activate`; `forget` also filters the stacks and collapses adjacent
duplicates; `close` pushes the `Closed` it returns onto `closed`;
`reopen(leaving)` calls `insert(closed.index, …)`. Invariants 4, 5 and 7 need
emptiness and "same note": S4 adds a `Place` trait bound (`is_empty`,
`same_note`) with two implementers, `app`'s `Place` and the proptest fake.

**Proptest:** `enum Op { Insert(usize), Activate(Index), Step(Direction),
Last, Close(Index), Commit(Index, Option<u8>), Forget(u8) }` over `vec(op(),
1..64)`; `Insert` draws `0..12` (past the end); `Index` is
`proptest::sample::Index`. Fake place: `#[derive(Default)] struct Fake { note:
Option<u8>, seq: u32 }`; `leaving` returns the active note with a new `seq` and
logs the call. A `#[cfg(test)] fn check(&self)` asserts M1–M3 after every op.
Proptests: `invariants_hold_over_any_sequence` (M1–M3),
`an_insert_lands_at_its_index_clamped` (M4),
`a_close_then_insert_at_its_index_restores_the_order` (M4),
`leaving_is_called_once_exactly_when_the_active_tab_is_left` (M5),
`a_left_tab_gives_back_the_place_it_was_left_with` (M5). Units:
`closing_the_last_tab_leaves_one_empty_tab_with_a_new_id` (M1),
`closing_the_active_tab_activates_the_most_recent_other` (M6),
`closing_another_tab_keeps_the_active_one` (M6),
`a_commit_to_a_tab_not_active_changes_nothing` (M7),
`forget_empties_only_matching_tabs` (M8), `step_wraps_both_ways` (M9),
`a_new_tab_goes_right_after_the_active_one`,
`closing_an_inactive_tab_does_not_call_leaving`,
`a_commit_to_an_inactive_tab_does_not_call_leaving` (the Fake's call log is
unchanged). Commit
`crates/tabs/proptest-regressions/`.

## Risks

- **`cmd-}` depends on the layout:** `⌘⇧]` on non-US layouts reports another
  character (`events.rs:420-431`). `ctrl-tab`/`ctrl-shift-tab` cover it everywhere.
- **`with_window` is silent under a lease** (Decision 2): reusing the
  subscription's code compiles and leaves focus on a dropped handle. Two tests
  assert the root is focused.
- **Stale offsets** in an inactive tab on the same note, until S2; a test pins
  that nothing panics.
- **A load for a note trashed before it lands** commits a trashing buffer —
  true today (`store.rs:114-132`), not made worse.
- **The missing-buffer branch in `show_place`** is unreachable without
  eviction; it forgets rather than panics.
- **Every shot changes** by the bar's height; vault scenes gain the backlinks
  column. Sidebar clicks do not move.
