# Tabs S2 — parked anchors

> **For agentic workers:** steps use checkbox (`- [ ]`) syntax. Written by an
> Opus planner on 2026-09-29, red/blue reviewed (Sonnet), findings folded in.

**Goal:** an inactive tab showing a note keeps its view as `Buffer` anchors,
so an edit to that note in another tab, an undo or a reload moves it with its
text. The anchors live in one app table, `Parked`; `park` and `unpark` are its
writers, and `NoteClosed` drops entries. `Tabs<P>` does not change.

**Spec:** `docs/superpowers/specs/2026-09-29-tabs-design.md` (A2 "Parked
anchors (S2)", A4, Risks, As built S0/S1). Rules: `CLAUDE.md`,
`.claude/rules/{shell,editor,vault,app-tests}.md`.

Every task: failing test first, implement, `cargo fmt -p inkra-text -p
inkra-editor -p inkra-app -p inkra-vault -p inkra-markdown -p inkra-index -p
inkra-tabs` (never `--all`), commit. One-line comments; tests in their own
file; never `cargo mutants --in-place`. Code shown is the intended shape: if a
real signature differs, adapt and say so.

## Decisions settled from the code

1. **Anchors resolve as `map_through` does, so the biases match.** `Diff::map`
   is "where an anchor with `bias` would resolve": `apply_diff` replays hunks
   last-first through `Buffer::replace` → `shift_anchors`
   (`text/src/diff.rs:44-54`, `:167-185`; `buffer.rs:433-437`). A reload
   reaches every open buffer, a parked one included, through `did_reload` →
   `apply_diff` (`vault/session/mod.rs:75-93`). `map_through`
   (`editor/src/state.rs:299-316`): a caret `Right`; a range start `Right`,
   end `Left` (`map_inward`, `:325-328`); crossed or empty collapses to
   `Selection::at(start)`; `reversed` kept on a non-empty range; goal
   `Goal::None`. Parking stores two anchors, start `Right` and end `Left`,
   even for a caret: for a caret c, `Right(c) >= Left(c)`, so the crossed case
   collapses at `Right(c)`, `map_through`'s caret branch. A proptest proves it
   (Task 1); if it fails on carets, use one `Right` anchor for a caret. The top
   line is `Left`, as `TopLine::mapped` (`app/src/editor/viewport.rs:62-67`);
   `below` is kept, bounded at restore by the row's height (`viewport.rs:221-229`).
2. **The goal survives only when nothing moved.** `unpark` returns the parked
   `Selection`, goal included, iff `buffer.version()` equals the version at
   park (`buffer.rs:84-89`) and the resolved range equals the parked one;
   otherwise the `map_through`-shaped selection with `Goal::None`. The version
   alone would keep a stale goal after an undo/redo round trip that moved an anchor:
   the blue team showed it on a scratch test — a caret at 5, delete `3..8`,
   undo: `version()` is back to V0, but the anchor resolves to 8 (`Right`) or 3
   (`Left`), because undo re-inserts at the collapsed point (`anchor.rs:26-35`).
   The range check is load-bearing.
3. **Park happens inside the `leaving` closure of `insert` and `activate`
   only.** `leave_active` calls `leaving` once per real leave
   (`tabs/src/lib.rs:197-200`); after `insert` (`:121-128`) and `activate`
   (`:131-141`) the left tab survives, inactive — the only case with something
   to park. `close` of the active tab (`:144-169`) and `commit` (`:173-181`)
   keep the plain `capture` (`shell/tabs.rs:29-34`): the tab is gone, or stays
   active (S4 pushes that value on `back`, as plain offsets). The closure is
   `|| park(&mut self.parked, left, self.bound.as_ref(), cx)`, `left =
   self.tabs.active()` read first; disjoint captures while `self.tabs` is
   borrowed (as `shell/tabs.rs:41`). `park` returns `Place { note, view: None
   }`: **anchors never enter `P`, and `Tabs` holds no stale view.**
4. **Unpark wherever `Tabs` hands back a place to show:** `activate`'s
   `Some(place)` (`shell/tabs.rs:111-116`) and `Closed.shown`
   (`:57-68`), both through `arrive(tab, place)` = `Place { view:
   self.parked.unpark(tab, cx), ..place }`, before `show_place` → `bind`
   (`activation.rs:118-152`), no `await` between; `bind`/`open_buffer` still
   clip. Closing an inactive tab calls `unpark(id)` and discards the view (its
   anchors are forgotten while the buffer lives); S5 passes that view to the
   closed-stack entry instead, as plain offsets. Closing the active tab finds
   nothing parked (I1); the last-tab fresh id (`lib.rs:152-158`) has no entry.
5. **On `NoteClosed`, entries drop without forgetting.** A shell helper
   `forget_note(id) -> bool` = `parked.drop_note(id)` then `tabs.forget(..)`,
   used by the `NoteClosed` subscription (`shell.rs:102-111`) and by
   `show_place`'s missing-buffer branch (`shell/tabs.rs:132-135`). `drop_note`
   is the table's third mutation: it removes entries, creating or resolving no anchor.
  It `retain`s over every entry of the note — one note can be parked under
  several tabs — never a single `remove`.
6. **The buffer and its anchors cannot separate.** `Anchor` is a bare index;
   against the wrong buffer it gives a wrong offset, not a panic
   (`text/src/anchor.rs:12`; `buffer.rs:412-418`). `ParkedView` owns its
   `Entity<Buffer>`, is not `Clone`, and `unpark(self, cx)` consumes it: a
   second `forget` (a panic, `buffer.rs:424-431`) cannot be written.
   `inkra-editor`'s `ParkedSelection::unpark(self, &mut Buffer)` has one
   caller, `ParkedView`.
7. **Park clips before it anchors.** `Buffer::anchor` asserts `≤ len` and a
   char boundary (`buffer.rs:396-407`); `capture` can return a waiting
   `ScrollTo::Top` no local edit mapped (`viewport.rs:184-190`). Park runs
   `ViewState::clipped` first.
8. **Nothing in `inkra-text` changes.** A park is 3 `anchor` calls, an unpark
   3 `resolve` + 3 `forget`, all O(1). `shift_anchors` walks every slot ever
   created, tombstones included (`buffer.rs:50-51`, `:433-437`): an edit to X
   costs O(3 × parks against X this session) — kilobytes per keystroke at
   human scale, beside `replace`'s O(len) shift. Task 5 benches it; "Anchor
   slot reuse" stays Deferred.
9. **The S1 stale-view test changes meaning.**
   `a_stale_view_in_another_tab_on_the_same_note_clips_on_return`
   (`shell/tests/tabs.rs:547-569`) still passes, but 0 now comes from the
   caret following its text, not a clip. Task 3 replaces it with tests that
   fail on S1's code.
10. **The S4 lever gets easier.** After S2 `Tabs` holds no view for any tab;
    `commit`'s leaving value stays plain, ready for `back`.

## Invariants

- **I1:** `Parked` has an entry for tab t **iff** t is inactive and its place has a note.
- **I2:** no `Place` stored in `Tabs` carries a `view` (S2 only; S4 relaxes it for stacks).
- **I3:** every entry's anchors were created in its own `buffer`, and are
  forgotten exactly once (by `unpark`) or dropped with their note (`NoteClosed`).
- **I4:** unparking gives what `map_through` gives for the same edits: range
  and `reversed`; the goal survives only if nothing moved; the top line maps as
  `TopLine::mapped`.
- **I5:** `park` runs only in the `leaving` closure of `insert`/`activate`;
  `unpark` only on a place `Tabs` just returned, or on a closed id.
- **I6:** park and unpark never panic: clipped before anchoring, resolved only
  against its own buffer.

The shell tests' `check` (`shell/tests/tabs.rs:45-52`) gains I1 and I2.

## Deliberately not done

- No change to `inkra-tabs`; parking lives in `app` (A2).
- No anchor slot reuse or batch API in `Buffer` (Deferred, trigger a profile).
- History stacks (S4), the closed stack (S5): S2 only routes an inactive
  close through `unpark`.
- The composition is not parked: a switch drops it (A3).
- No `Selection::map_offsets`; the shared piece is `Selection::settled`.
- No `Drop` on `ParkedView`: no `cx`, and `NoteClosed` drops without forgetting.

## Risks

- **Wrong buffer, silent wrong offset:** ownership (Decision 6) and I3; the
  two-tabs reload test would catch a mix-up.
- **Double forget panics:** impossible by move; `Parked::park` asserts no entry.
- **Slot growth** linear in switches per note; Task 5 measures.
- **Goal after an undo/redo round trip** is dropped when an anchor moved: a
  lost pixel hint, not a lost position.
- **`EditorView::buffer()` is `cfg(test)`** (`editor/mod.rs:222-226`):
  parking stays inside `editor/` through `self.input.buffer()`.
